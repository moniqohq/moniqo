# Moniqo Roadmap

Moniqo is a privacy-first, open-source budgeting application focused on
clarity, financial awareness, and a modern user experience.

This roadmap describes the direction of Moniqo beyond the current MVP.
Implementation details and active work are tracked through GitHub Issues,
Projects, and Milestones.

See also the public roadmap: [https://moniqo.in/roadmap/](https://moniqo.in/roadmap/)

---

## Current Status

### ✅ MVP — Foundation & Core Budgeting

The initial Moniqo MVP is complete.

It establishes the foundation of the application and delivers the primary
budgeting workflow.

Implemented:

- Foundation & infrastructure
- Authentication & session management
- User management
- PostgreSQL data model
- Modular monolith architecture
- REST API
- Core budget and account management
- Categories and transactions
- Monthly budgeting
- Zero-based budgeting workflow
- Transaction reconciliation
- Account transfers
- Initial UI/design system
- Development and CI/CD infrastructure

# Roadmap

## 📋 Phase 1 — Financial Planning & Insights

**Goal:** Help users understand where their money is going and plan ahead.

Planned:

- Savings goals
- Spending analytics
- Reports & charts
- Recurring transactions
- Budget trends
- Category insights
- Forecasting

**Status:** Planned

---

## 📋 Phase 2 — Collaboration & Shared Budgets

**Goal:** Make Moniqo useful for households and shared financial planning.

Planned:

- Shared budgets
- Role-based permissions
- Household budgeting
- Multi-user budget management
- Real-time synchronization
- Conflict resolution

**Status:** Planned

---

## 📋 Phase 3 — Data Portability & Integrations

**Goal:** Make it easy to bring financial data into and out of Moniqo.

Planned:

- Import/export tools
- CSV support
- Data migration tools
- Public API
- Webhooks/integrations

**Status:** Planned

---

## 🔮 Phase 4 — Platform Expansion

**Goal:** Make Moniqo available across more platforms and extensible for
the community.

Planned:

- Mobile application
- Desktop application
- Plugin system
- Community integrations
- Extended API capabilities

**Status:** Future

# Moniqo Roadmap

Moniqo is a privacy-first, open-source budgeting application focused on
clarity, financial awareness, and modern user experience.

This roadmap outlines the planned direction of the project.
Implementation details and active work are tracked through GitHub Issues,
Projects, and Milestones.

---

# Guiding Principles

- Privacy-first
- Zero-based budgeting
- Clean and understandable financial workflows
- Open-source and contributor-friendly
- Modern, accessible UI/UX

---

# Current Status

Current Phase: Foundation & Core Budgeting

Primary Focus:
- Core budgeting engine
- Transaction workflows
- Budget/account architecture
- Stable API contracts

---

# Planned Roadmap

## Phase 1 — Foundation & Infrastructure

Goal:
Establish the core architecture and development foundation.

Planned:
- Authentication & session management
- User management
- PostgreSQL schema
- Modular monolith architecture
- Docker development environment
- CI/CD pipeline
- Initial design system
- REST API foundation

Status: In Progress

---

## Phase 2 — Core Budgeting Experience

Goal:
Deliver the primary budgeting workflow.

Planned:
- Budgets
- Accounts
- Categories
- Transactions
- Monthly budgeting
- Zero-based budgeting workflow
- Transaction reconciliation
- Transfers between accounts

Status: Planned

---

## Phase 3 — Financial Planning & Insights

Goal:
Improve financial visibility and planning capabilities.

Planned:
- Savings goals
- Spending analytics
- Reports & charts
- Forecasting
- Recurring transactions
- Budget trends
- Category insights

Status: Planned

---

## Phase 4 — Collaboration & Sync

Goal:
Enable collaborative financial management.

Planned:
- Shared budgets
- Role-based permissions
- Household budgeting
- Real-time synchronization
- Conflict resolution strategies

Status: Planned

---

## Phase 5 — Ecosystem & Platform Expansion

Goal:
Expand Moniqo into a broader financial platform.

Planned:
- Mobile application
- Desktop Application
- Import/export tools
- Plugin system
- Public API
- Bank integrations

Status: Future
